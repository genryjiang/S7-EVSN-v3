# Test Coverage Evidence

Use this skill for coverage, traceability, and verification-evidence work.

## Core Guidance

- Do not claim ISO 26262 compliance from tests alone.
- Record what was tested, on what platform, with what configuration.
- Distinguish unit, integration, SIL/emulation, QNX-target, HIL, manual, and analysis evidence.
- Link tests to requirements, hazards, defects, work items, or change IDs where available.
- Identify missing test evidence honestly.
- Include coverage expectations and gaps, but do not treat line coverage as proof of safety.
- Preserve assumptions, tool versions, target details, inputs, outputs, and residual risks when recording evidence.
